# FLM Companion 0.5.6

## Added

- Dynamic System RAM detection resolving physical memory type (e.g. LPDDR5X) and clock speed (e.g. 8000 MHz) via Windows CIM queries.
- Offline bundled typography via Plus Jakarta Sans and JetBrains Mono font packages.
- User-side Markdown & GFM rendering in Chat (syntax-highlighted code blocks, tables, inline backticks).
- Tab indentation in Chat textarea (inserts 2-space indent instead of shifting browser focus to Send).
- Robust GitHub release scraping fallback when API hits anonymous 403 rate limits.

## Improved

- Unified header alignment and optical 4px inset across all 5 main views (Server, Models, Chat, Settings, About).
- Cleaned up redundant section subheaders in Settings for a leaner presentation.
- Refreshed light theme with warm oatmeal/alabaster tones (`#FAF8F5`, `#292524`), paired high-contrast console logs, and amber status indicators.
- Pure AMOLED pitch-black dark theme (`#000000` canvas, `#09090b` cards) with scoped `@custom-variant dark` preventing OS dark mode leakage.
- Excluded Chat Send button from keyboard tab order (`tabIndex={-1}`) to prevent accidental submissions.
- Error dialogs display underlying system error details for immediate visibility.

## Fixed

- Detached installer execution and immediate process exit to eliminate self-update binary file locks.
- Removed unsupported `-Verb RunAs` parameter for MSI installer execution in PowerShell.
- Added missing `release-assets.githubusercontent.com` capability permissions for Tauri downloads.
- Handled HTTP 301 redirects for upstream repository movements (`ROCm/FastFlowLM`).
- Fixed vertical alignment of ModelsView columns to ensure both card lists start at the exact same vertical pixel.
