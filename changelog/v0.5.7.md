# FLM Companion 0.5.7

## Added

- Static API model alias (`flm-auto`) exposed in `/v1/models` and dynamically routed to the currently launched FLM model.
- Live Settings toggle (`Static API Model (flm-auto)`) with English, French, and Japanese translations, plus Developer API snippet support.
- `GET /v1` API info response pointing clients to `/v1/models` and `/v1/chat/completions`.
