# FLM Companion 0.5.5

First public-facing release of the fork.

## Added

- Chat connected directly to the active FLM server.
- Collapsible streamed reasoning display with final answers rendered separately.
- Persistent model, launch settings, and response preset selection.
- Companion-owned OpenAI-compatible API proxy for the active model.
- Model catalog search and installed-model management.
- Accurate context metadata, launch context, model maximum context, TTFT, and context-use visibility.
- Model downloads with progress, cancellation, exact FLM-reported byte counts, and quit handling.
- Multiline Chat input, Enter-to-send, Shift+Enter newline, Escape-to-stop, and streaming cancellation.
- English, French, and Japanese interfaces.
- Windows NSIS and MSI packaging with bundled WebView2 support.

## Improved

- Server and model screens remain responsive across tab switches.
- Chat top bar shows active model and launch preset without duplicate configuration.
- Composer uses one full-width control with integrated send/stop action.
- Tray exposes installed and startable models without unnecessary catalog work.
- FLM process and download cleanup covers stop, restart, hide, close, quit, and failure paths.
- Branding and update metadata now identify FLM Companion and the fork publisher.

## Fixed

- Accurate installed and downloadable model sizes.
- Context metadata fallback when FLM model listings omit maximum context.
- Windows GNU linker/build compatibility.
- Stale FLM process cleanup and API proxy request handling.
