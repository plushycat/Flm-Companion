## v0.5.5

### Fixed

- FLM auto-update now launches installers as tracked subprocesses.
- FLM updates now validate installer exit code and installed version before refreshing the app.
- FLM updates stop the active server before replacing installed files.
- FLM updates support current `flm-setup.msi` releases and legacy `flm-setup.exe` releases.
- FLM minimum version is aligned to `0.9.37`.
- Companion API proxy recalculates `Content-Length` after request changes.

### Added

- Chat-only Caveman mode remains local to Chat.
- Server launch options now include Caveman mode for all proxied API clients.
- Caveman mode uses a stronger, shared system instruction.

### Improved

- FLM update refresh happens only after verified installation success.
